# MoonSTOMP 0.3.1

本页说明版本内容与发布门，不能代替实际上传。是否已发布以Mooncakes版本、checksum和精确registry消费者回执为准；0.3.0保留旧行为，不能覆盖它。

0.3.0的Mac真实TLS消费者暴露了启动心跳边界：Classic6.3.2首次空闲心跳约在2R后才发出，再加异步调度，原Client的2R接收期限可能先关闭。修复把检查相位R与100ms调度余量相加：`tolerance=min(R+100ms,2147483647ms)`，仍在`elapsed > R+tolerance`时关闭。常见R下为2R+100ms；公共HeartbeatClock默认100ms、方向禁用、API及重连/重发策略不变。

这是有界互操作修复，代价是故障检测略晚；不是任意调度延迟、长稳或生产部署保证。原0.3.0失败记录不改写。来源、时序与取舍见[根因记录](heartbeat-phase-margin.zh-CN.md)。

测试夹具继续转发全部EOL，只在CONNECTED至少一个协商周期后的空闲窗口计数，排除尾随换行；100/1000ms均需先观察双向心跳，再主动丢弃broker心跳并验证超时、无重连、端口及私钥清理。严格下一毫秒关闭、partial/empty输入、禁用及极限值回归保留。

发布门：新PR精确head常规检查与固定broker手动CI（含100/1000ms）通过后正常合并，核合后检查与包清单，临发布防重，使用既有官方CLI登录发布一次；未知结果先只读核实。真实发布后在全新消费者从registry精确安装0.3.1，重验本次失败路径与核心/多版本/异步API，不用workspace/path替代。
